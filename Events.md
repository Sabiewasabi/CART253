# **1.  Mofusand Mayhem**

SABRINA RATH

[View this project online](https://sabiewasabi.github.io/CART253/prototypes/events/events-prototype-1/)

[View the code to this project](https://github.com/Sabiewasabi/CART253/blob/main/prototypes/events/events-prototype-1/js/mofusand-mayhem.js)

## Description

>This project is a simple stamp tool that allows the user to click on the canvas and stamp different images onto it. Each time the user clicks, a sound effect will play and the next image in the array will be stamped onto the canvas at the mouse position. The images will loop back to the first one after the last image is used.

>The experience is controlled via mouse clicks, and the user can create a fun and interactive experience by stamping different images onto the canvas.

# **2. What's your RNG today? Dev struggles edition**

SABRINA RATH

[View this project online](https://sabiewasabi.github.io/CART253/prototypes/events/events-prototype-2/)

[View the code to this project](https://github.com/Sabiewasabi/CART253/blob/main/prototypes/events/events-prototype-2/js/rng.js)

## Description

> This project is a simple interactive experience that allows the user to click on a mystery box to reveal a random prize. The prizes are all related to common struggles that developers face, such as debugging, coding, and staying energized.

> This experience is controlled via mouse clicks, and the user can click on the box to reveal a prize, and then click again to close the box and try again. The prizes are displayed with a hollow gradient glow behind them, and the name of the prize is displayed below the image. The project also includes a sound effect that plays when a prize is revealed.

# 3. **Bunbun Wants Carrots**

SABRINA RATH

[View this project online](https://sabiewasabi.github.io/CART253/prototypes/events/events-prototype-3/)

[View the code to this project](https://github.com/Sabiewasabi/CART253/blob/main/prototypes/events/events-prototype-3/js/bunbun-wants-carrots.js)

## Description

> This project is a simple interactive game where the player guides a bunny around the screen to catch a bouncing carrot. Each carrot caught adds to the score, and the goal is to eat as many as possible before the 30-second timer runs out.

> This experience is controlled via mouse movement, and the bunny follows the cursor with a soft glow behind it. The carrot bounces off the edges of the canvas, and catching it sets off a shockwave ripple where it was eaten, then sends it to a new random spot. The timer turns red in the final 10 seconds, and when time's up, the game displays the total number of carrots eaten. The project also includes a crunch sound effect that plays whenever a carrot is caught.
